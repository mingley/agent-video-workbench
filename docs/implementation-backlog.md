# Implementation completion and remaining qualification

The current source also offers opt-in canonical Unicode/no-space phrase
search, user-supplied checks against frozen rendered files, and chapter drafts
from selected markers. Sidecars reject sub-millisecond collapsed cues before
encoding; review ranges use verified output timing. See [delivery checks](creator-delivery-checks.md)
and [current evidence](implementation-status.md). Checked batch packages now
bind briefs to individual frozen outputs. Pre-render constraint planning, real
creator trials and account-specific publication remain open.

The current [creator toolkit](creator-agent-toolkit.md) adds agent-visible
media, external moment-search and word/translation proposals, sampled subject
reframing, imported review decisions, thumbnail candidates and optional
spectral noise reduction. Semantic understanding, alignment, translation and
subject detection still need separately supplied observations or providers,
and their quality has not been established by the generated fixtures.

Current source also adds [frozen plain-cut comparison](compare-edits.md), a
range marker in delivered review pages, and a refusal for caption cues that
would vanish at the output frame rate. Bounded scene/silence inspection
reports unavailable evidence when its timestamp or decoded coverage cannot be
established. Other comparison types and broader media qualification remain open.

October 30 source additions: bounded literal search across transcript cues,
per-boundary cue context, source-range feedback remapping, and copyable review
references extend the agent/creator loop. Analysis requests are validated before
queueing, and protected-content rendering and subtitle sidecars use consistent
track-solo rules. These are source-build changes, not additions to the published
0.3.1 release. [Creator opportunities](creator-agent-opportunities.md) separates
remaining proposals and real-user qualification from implemented behavior.

October 6 addition: [source-context paper edits](edit-planning.md) now provide
briefs, per-cut reasons, explicit speech handles and risk review, source-window
proxy requests, omitted material, revision-bound plan application and stale review
detection. Frozen review pages show the intent beside each named version.
Real performance judgment and word-level alignment remain qualification work;
the planning tools keep the external agent responsible for playback and choices.

October 5 addition: main's 0.4.0 source build implements plain-cut PQ/HLG
preservation, source-matched defaults, editorial preflight and separate verified
SDR previews. [Natural edits](natural-edit.md) and [current evidence](implementation-status.md)
describe that scope. HDR compositing/grading/captions, real camera/display
qualification and proprietary dynamic metadata remain extensions.

The former N01–N08 implementation gaps are addressed in the 0.3.1 Linux CLI/MCP
route. [Implementation status](implementation-status.md) links actual evidence;
[product plan](product-plan.md) retains the broader M1–M5 acceptance ambitions.
An implemented feature and camera/host/appearance certification are different gates.
