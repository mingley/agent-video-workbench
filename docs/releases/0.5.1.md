# Agent Video Workbench 0.5.1

Faster source browsing and review previews with the same decoded media and
original-timeline mappings.

- Subprocess completion wakes the worker immediately, while cancellation,
  deadlines, process-group cleanup and output/resource limits remain enforced.
- Source storyboards combine bounded groups of accurately sought samples;
  larger coded frames retain sequential extraction. Partial pages and observed
  frame clocks retain their original meaning.
- Preview validation collects decoded frame timestamps and validates audio in
  one pass. Actual byte/duration limits, frame mapping and integrity checks stay
  in place. Impossible byte budgets include the smallest observed attempt.
- Internal PRs reuse native push checks, and release-request-only updates
  publish qualified archives without rebuilding them.

Five interleaved generated-source runs on Linux x86_64 measured a 61% reduction
in twelve-frame storyboard time, a 16% reduction in ten-second preview time,
and roughly half the cached-request latency. Parallel storyboard decoding uses
more memory. See [research, measurements and limits](../source-view-performance.md).
These figures do not establish camera, model or hosted-agent performance.

Native Linux x86_64/ARM64 archives require the repository's existing release
qualification and immutable publication checks. Source originals, editing
history and the service request contract are preserved.
