Agent-operated video workbench for Linux x86_64 and ARM64 through CLI JSON and MCP stdio.

Adds original-preserving PQ/HLG HDR-to-Rec.709 SDR conversion; source SAR/rotation/timing normalization; selective source restore; versioned profiles/templates and font libraries; independent format/language variants; B-roll, J/L cuts, fades, ducking and measured loudness; artifact-based review and frozen batch MP4/SRT/VTT/cover/sheet/HTML delivery; resumable scoped transfers; PTS frame indexes, mapped proxies, editable CPU tracking/pans and provider contracts; catalog, automatic lease-aware retention, verified backup/restore/relink and supported-cut OTIO interchange.

Both native Ubuntu 24.04 runners passed rustfmt, strict Clippy (-D warnings), 30 Rust tests, schema checks, media/creator/audio/transfer/analysis/timeline/short-4K qualification, no-root bundle installation and the official MCP SDK workflow. See https://github.com/mingley/agent-video-workbench/actions/runs/37097054216 . Release archives were verified against the run's checksums and embedded source commit 7c520b50f44e1286563693180311c6030afed877.

Verify the matching SHA256SUMS and install into a fresh directory with the included avw/install.sh. install-release.sh automates native download/verification; setup-media.sh prepares the separately licensed FFmpeg 8 dependency; setup-asr.sh is optional local English transcription setup. Runtime needs compatible glibc Linux, FFmpeg 8 and a licensed imported font. The app binary requires no Cargo, Node, GUI or root.

Delivery is SDR H.264/AAC. Generated tests do not certify real phone appearance, Dolby Vision profile-5/Log/HDR-output masters, complex script shaping, Mac/Windows or arbitrary consumer-agent accounts. See docs/implementation-status.md and AGENT_GUIDE.md in the archive for the exact contract. Local real Whisper and a low-resolution one-hour-source benchmark are separately qualified; short 4K/60 input does not imply one-hour 4K performance.
