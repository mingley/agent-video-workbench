# Agent Video Workbench 0.5.2

Browse long originals more easily and avoid repeated work while retaining
source integrity and durable job results.

- Storyboard tiles contain ready-to-use budget-preview requests centered on
  observed frames. Storyboard scopes span up to 24 hours and can begin after
  the 24-hour source position. Editing, transcript and discovery source-position
  limits remain separate.
- Initial render verification hashes a shared managed original once when
  duplicate asset records point to unchanged identical bytes. Every asset's
  identity and regular path is still validated; legacy HDR metadata recovery
  may recheck originals.
- Job completion atomically respects cancellation that was accepted before
  finalization. Shared caches and previous successful artifacts are preserved.
- ASR uses the source audio clock when mapping cues, and refuses gaps or
  ambiguous clocks that cannot be mapped safely. Existing transcript artifacts
  remain accessible, but older cached transcripts may have shifted timestamps;
  new requests transcribe again using a separate timing-aware cache. Review and
  re-import affected transcripts as needed; project history is not rewritten.
  New cache identities include the asset, and incomplete pairs do not overwrite results.

See the [source browsing guide](https://github.com/mingley/agent-video-workbench/blob/v0.5.2/docs/source-views.md)
for preview budgets, coverage limits, and usage. The native qualification
includes a generated duplicate-asset before/after benchmark and an offline fake
ASR provider test; neither establishes real-camera or speech-recognition quality.

## Qualification and measurements

[Native qualification](https://github.com/mingley/agent-video-workbench/actions/runs/42443616525)
passed on Linux x86_64 and ARM64 at source commit `61acfc404ac9001e33cfdd04d0ba73a938bb0e72`, with
211 Rust tests passing and two existing tests ignored on each architecture.
The generated-media and official MCP checks included 0.5.1 cache compatibility,
long-source storyboards and ASR clock regressions.

On the x86 runner (AMD EPYC 7763, four logical CPUs), three interleaved runs of
a warm generated 640×360 SDR source imported under five IDs measured median
initial original verification at **240.5 ms → 48.4 ms**. The 68.6 MB fixture
includes a 64 MiB sparse MP4 free box. Decoded audio and video matched; this
does not establish a general export, unique-source, HDR or 4K speedup.

A separate four-sample-per-version comparison using generated 60-second AAC and
a constant-output fake provider measured uncached ASR worker medians at
**99.9 ms → 146.3 ms** with the clock audit. This exposes audit overhead on
that warm shared runner; it does not measure real speech-model throughput or
accuracy. Existing transcripts remain unchanged and may need reanalysis.
