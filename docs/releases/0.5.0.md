# Agent Video Workbench 0.5.0

Browse long originals through cached, paginated source storyboards and request
small, precisely mapped review clips with explicit duration and byte budgets.

- `source-storyboard` returns observed frame timestamps, source-clock mappings,
  sparse-coverage disclosures and bounded active-transcript excerpts. Pages can
  be delivered as verified PNG content through CLI JSON or MCP.
- `budget-preview` measures actual output duration/bytes, validates full decoding
  and pairs proxy frames with the original presentation timestamps. It preserves
  variable frame rates and tries bounded resolution/quality reductions for size.
  Impossible or ambiguous requests fail instead of returning oversized media.
- Earlier performance fixes share verification with contact-sheet generation,
  add render-stage timings and scriptable result extraction, reject invalid
  imports before staging, and retain correct references for very short sheets.

See [source views](https://github.com/mingley/agent-video-workbench/blob/v0.5.0/docs/source-views.md) for usage, limits and coverage caveats.
Storyboards can miss brief events; previews are review derivatives. Original
media and editing history remain authoritative. No semantic model or hosted
agent acceptance is bundled. Linux x86_64 and ARM64 bundles use the existing
native qualification and immutable publication pipeline; consult the final
qualification record for exact source/run identities.

New source-view job records require 0.5.0. Keep a pre-upgrade backup if you need
to return to an older binary; older binaries may not understand these job kinds.
